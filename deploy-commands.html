BOSTON TRACKER - Comandos de Deploy

Orden sugerido para subir cambios al repo y desplegar en el VPS con PM2.

1. Local

commit + push
  1. Ver estado antes de subir 
    git status --short
  2. Agregar todos los cambios 
    git add -A
  3. Crear commit 
    git commit -m "fix: battery tracking and dashboard updates"
  4. Subir al remoto 
    git push origin main

2. VPS

PM2
  1. Entrar al proyecto 
    cd /var/www/boston-tracker
  2. Actualizar código 
    git pull origin main
  3. Backend: instalar, compilar y reiniciar 
    cd backend && npm install && npm run build && pm2 restart boston-backend
  4. Dashboard: instalar, compilar y reiniciar 
    cd ../dashboard && npm install && npm run build && pm2 restart boston-dashboard
  5. Verificar procesos 
    pm2 status
  6. Revisar logs si algo falla 
    pm2 logs boston-backend --lines 50
pm2 logs boston-dashboard --lines 50
Si el VPS usa otra ruta, cambia /var/www/boston-tracker por la ruta real del clone.
